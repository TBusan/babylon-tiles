# Babylon.js 地图瓦片渲染实现计划

## 项目概述

参考 `three-tile` 项目，使用 Babylon.js 实现相同功能的 3D 地图瓦片渲染系统。该系统支持动态 LOD（细节层次）、多数据源加载、地形高程渲染等功能。

## 二、核心模块实现步骤

### 2.1 坐标投影系统 (Projection)

**实现目标**: 将地理坐标（经纬度）转换为世界坐标

**关键接口**:

```typescript
interface IProjection {
	ID: string; // 投影类型标识
	lon0: number; // 中央经线经度
	mapWidth: number; // 地图宽度
	mapHeight: number; // 地图高度
	mapDepth: number; // 地图深度

	// 地理坐标投影到地图坐标
	project(lon: number, lat: number): { x: number; y: number };

	// 地图坐标反投影到地理坐标
	unProject(x: number, y: number): { lon: number; lat: number };
}
```

**实现类**:

- `WGS84Projection` - 经纬度直接线性投影
- `WebMercatorProjection` - Web Mercator 投影（EPSG:3857）

**实现要点**:

- 中央子午线支持（-90°, 0°, 90°）
- 经纬度范围裁剪
- 投影边界计算

### 2.2 数据源系统 (Source)

**实现目标**: 定义瓦片数据来源的抽象接口

**关键接口**:

```typescript
interface ISource {
	dataType: string; // 数据类型标识

	projectionID: string; // 投影类型
	minLevel: number; // 最小显示级别
	maxLevel: number; // 最大显示级别

	// 获取瓦片 URL

```

**实现类**:

- `XYZTileSource` - XYZ 标准瓦片源
- `ArcGisSource` - ArcGIS 影像源
- `DemSource` - 地形高程数据源

**实现要点**:

- 支持多个影像源叠加
- URL 模板替换（{x}, {y}, {z}）
- 边界范围限制

### 2.3 瓦片类 (Tile)

**实现目标**: 实现动态 LOD 的瓦片节点

**关键属性**:

```typescript
class Tile extends TransformNode {
	readonly x: number; // 瓦片 X 坐标
	readonly y: number; // 瓦片 Y 坐标
	readonly z: number; // 瓦片层级

	private _model: Mesh; // 瓦片网格
	private _subTiles: Tile[]; // 子瓦片
	private _bbox: BoundingBox; // 包围盒
	private _checkPoint: Vector3; // 检测点
}
```

**关键方法**:

- `update(params)` - 每帧更新瓦片状态
- `LOD(params)` - LOD 评估与子瓦片创建/删除
- `load(loader)` - 加载瓦片数据
- `unload(loader)` - 卸载瓦片数据

**实现要点**:

- 四叉树结构（每个瓦片可分裂为 4 个子瓦片）
- 基于相机距离的 LOD 判断
- 视锥体剔除（Frustum Culling）
- 包围盒计算与碰撞检测
- 瓦片可见性管理（只有 4 个兄弟瓦片都加载完成才显示）

**LOD 评估逻辑**:

```typescript
// 计算瓦片到相机的距离比例
const distRatio = distanceToCamera / tileSizeInWorld;

// LOD 判断
if (distRatio < LODThreshold && z < maxLevel && inFrustum) {
	// 创建子瓦片
	action = LODAction.CREATE;
} else if (distRatio > LODThreshold * 2 && subTiles) {
	// 删除子瓦片
	action = LODAction.REMOVE;
}
```

### 3.2 相机控制 (TileMapControls)

**实现目标**: 实现地图漫游相机控制

**两种模式**:

1. **MAP 模式** - 类似地图应用
   - 左键：平移
   - 中键：缩放
   - 右键：旋转

2. **ORBIT 模式** - 类似 3D 编辑器
   - 左键：旋转
   - 中键：缩放
   - 右键：平移

**动态行为**:

- 距离越远，缩放速度越快
- 高空时限制旋转角度
- 防止相机钻入地下
- 自适应远/近裁剪面

**Babylon.js 实现**:

- 继承 `ArcRotateCamera`
- 重写输入处理
- 动态调整 `lowerRadiusLimit` 和 `upperRadiusLimit`

## 七、关键技术点

### 7.1 坐标系转换

```typescript
// 地理坐标 → 世界坐标
geo2world(geo: Vector3): Vector3 {
    const mapPos = this.projection.project(geo.x, geo.y);
    const localPos = new Vector3(mapPos.x, mapPos.y, geo.z);
    return this.localToWorld(localPos);
}

// 世界坐标 → 地理坐标
world2geo(world: Vector3): Vector3 {
    const localPos = this.worldToLocal(world);
    const geo = this.projection.unProject(localPos.x, localPos.y);
    return new Vector3(geo.lon, geo.lat, localPos.z);
}
```

### 7.2 瓦片四叉树分裂

```typescript
createChildren(tile: Tile): Tile[] {
    const { x, y, z } = tile;
    const nextZ = z + 1;
    return [
        new Tile(x * 2, y * 2, nextZ),
        new Tile(x * 2 + 1, y * 2, nextZ),
        new Tile(x * 2, y * 2 + 1, nextZ),
        new Tile(x * 2 + 1, y * 2 + 1, nextZ)
    ];
}
```

### 7.3 LOD 阈值计算

```typescript
// 距离比例 = 相机距离 / 瓦片世界大小
const distRatio = cameraPosition.distanceTo(tileCenter) / tileWorldSize;

// 阈值判断
const needsDetail = distRatio < LODThreshold;
```

### 7.4 视锥体剔除

```typescript
// Babylon.js 视锥体检测
const frustumPlanes = new Frustum(null);
frustumPlanes.updateToMatch(camera);

const inFrustum = frustumPlanes.intersectsBox(tileBoundingBox);
```
